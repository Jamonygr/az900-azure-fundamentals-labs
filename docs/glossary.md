# Glossary

| Term | Meaning in this curriculum |
| --- | --- |
| Authentication | Establishing who an identity is. |
| Authorization | Deciding what that identity may do. |
| Availability zone | A physically separate zone with independent supporting infrastructure within a supported region. |
| Consumption billing | Charges based on measured usage and applicable rates. |
| Control plane | APIs that manage resource configuration and lifecycle. |
| Data plane | Operations on a service's data, such as reading a blob. |
| Elasticity | Adjusting provisioned capacity as demand changes. |
| IaaS | Provider-managed infrastructure with customer-managed operating systems and applications. |
| PaaS | Provider-managed infrastructure and platform for customer applications. |
| SaaS | A provider-operated application used by customers. |
| Management group | A scope for organizing subscriptions and inherited governance. |
| Resource group | A management container for resources with a related lifecycle. |
| Region | A geographic Azure deployment area containing datacenters. |
| RBAC | Role assignments that grant actions at a specified scope. |
| Policy | Rules that evaluate or constrain resource configuration. |
| Lock | A management-plane protection against deletion or changes, depending on lock type. |
| Serverless | A model in which platform infrastructure is managed for the workload; billing varies by service and plan. |
| Shared responsibility | Division of security and operational duties between customer and provider. |
| Subscription | A resource, access, governance, and billing scope. |
| Tag | A key/value label used to organize resources; tags are not automatically inherited. |
| Zero Trust | Verify explicitly, use least privilege, and assume breach. |

See individual labs for qualifications and source links.
