# Artwork notes

The visual refresh uses original artwork for this independent AZ-900 learning project. Assets are covered by the repository's MIT license. Illustrations are conceptual learning aids, not Microsoft product screenshots or a promise of live-tested deployments.

## Cover artwork

- Asset: [Azure cloud cover](docs/assets/illustrations/azure-cloud-cover.png).
- Created with the built-in imagegen tool using the imagegen skill. No CLI/API-key fallback was used.
- The cover is symbolic artwork. Instructional labels are ordinary page text, while teaching diagrams remain editable SVGs.

Final generation prompt:

> Use case: stylized-concept. Asset type: original wide cover artwork for an independent AZ-900 Azure Fundamentals learning repository and website. Create a polished, inviting cloud-computing illustration in an Azure-inspired blue, periwinkle-purple, cyan, and soft-white palette. A large sculptural cloud connects to a small isometric datacenter, a database cylinder, a network of service nodes, and a security shield, with one subtle open learning book grounding the scene. These are symbolic cloud capabilities, not a literal deployed architecture. Premium editorial 3D illustration with rounded geometric forms, soft ambient lighting, smooth materials, subtle shadows and clean gradients; crisp shapes, tasteful detail, generous breathing room. Compose as a very wide horizontal banner, approximately 2.5:1, with the central-right cloud and service cluster balanced by uncluttered light background on the left for separately rendered webpage text. Keep important objects within the central 80 percent so responsive cropping remains useful. Background is light off-white with a restrained pale-blue/purple glow. No lettering, numbers, logos, watermarks, screenshots, UI panels, people, tiny label text, or busy decorative clutter. Visually warm, professional, and engaging for complete beginners.
